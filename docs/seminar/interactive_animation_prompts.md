# ゼミ用インタラクティブアニメーションのプロンプト（Grok向け）

ゼミのスライドを補う、ボタンで1段階ずつ進み、スライダーで条件を変えられるアニメーションを作るためのプロンプト。Grokに貼り付けて、1つのHTMLファイルとして作ってもらう想定。3つある。

| プロンプト | 対応するスライド | 見せたいこと |
|---|---|---|
| A　画像のLIMEと多クラスLIME | LIMEのおさらい（1）（2）、多クラス分類でのLIMEのやり方、手法 | スーパーピクセル、摂動画像、回帰、ヒートマップ。クラスごとに10枚になること。6−0の差が1枚の説明になること |
| B　仮定1の確かめ方 | 仮定1の確かめ方（1）（2） | ずれの取り方、動くクラスの数、必要な軸の数 |
| C　決定係数 R² による評価 | 忠実さの測り方 | 説明のずれと、平均で答えたときのずれを棒で集計し、R² を出す |

## 使い方と注意

- 各プロンプトは単独で動くように書いてある。上の「共通の指定」を、それぞれの先頭に貼る
- 数値の例はスライドと同じにしてある（手書き数字の実データの例、またはスライドの説明用の例）
- 1回で思いどおりにならないことが多いので、動かしてみて「○○のボタンを押しても棒が動かない」のように直してもらう
- できあがったHTMLは、ブラウザで開けば動く。発表ではブラウザを全画面にして使う

## 共通の指定（各プロンプトの先頭に貼る）

```
ゼミ発表で使う、インタラクティブなアニメーションを1つのHTMLファイル（HTML・CSS・JavaScriptを1ファイルにまとめる）で作ってください。外部ライブラリは使わず、描画はCanvasかSVGで行ってください。

共通の仕様
- 画面は16:9。左に大きな描画エリア、右に説明文と操作パネルを置く
- 画面下に「最初から」「戻る」「次へ」「自動再生（ON/OFF）」のボタンを置く。「次へ」を押すと1段階ずつアニメーションが進む。キーボードの右矢印でも「次へ」、左矢印で「戻る」
- 各段階で、右上に「ステップ n／全体数」と、その段階で何をしているかの短い説明文（日本語）を表示する
- スライダーを動かしたら、その場で計算し直して描画を更新する（今の段階は保つ）
- 動きは0.5〜1秒程度のなめらかなイージング。白い背景、フラットなデザイン、読みやすい日本語フォント（sans-serif）
- 色の決まり　クラス0は青（#2F78A8）、クラス6は赤（#D9532B）、クラス9は黄（#E3A21A、ただし星が黄色になる平面の図では緑 #3A9D7A）、クラス2は赤（#D9532B）、クラス3は青（#2F78A8）、強調は朱色（#D9532B）、そのほかのクラスは灰色（#9AA3B2）、文字は濃紺（#1D2433）
- 数値は小数第2位まで表示する
```

## プロンプトA　画像のLIMEと多クラスLIME

```
[共通の指定]

テーマ　「画像に対するLIMEがどう説明を作るか」と「多クラスではクラスごとに説明が10枚になること」を、手書き数字の例で段階的に見せる

登場するもの
- 8×8画素の手書き数字（6）。各画素の濃さ（0〜1）は次のとおり（行は上から、列は左から）
  [[0,0,0.12,0.69,0.81,0.25,0,0],[0,0,0.75,1,0.81,0.94,0,0],[0,0,1,0.56,0.06,0.19,0,0],[0,0.25,1,0.38,0.88,0.56,0.06,0],[0,0.44,1,1,1,1,0.38,0],[0,0.06,1,0.88,0.25,1,0.5,0],[0,0,0.75,1,0.81,1,0.12,0],[0,0,0.12,0.62,1,0.44,0,0]]
- スーパーピクセルは3つ　A＝左の縦線（列0〜2）、B＝右上（行0〜3、列3〜7）、C＝右下（行4〜7、列3〜7）
- AI（分類器）は、どの領域を残したかで次の確率を返すことにする（A,B,C は残したら1、隠したら0）
  - 6の確率 ＝ 0.40 ＋ 0.30A − 0.30B ＋ 0.10C
  - 0の確率 ＝ 0.45 − 0.30A ＋ 0.30B − 0.05C
  - 9の確率 ＝ 0.05 ＋ 0.05×(1 − C)
  - 残りの7クラスは、合計0.05を等分
  - スライダー「AIの出力のゆらぎ」が0より大きいときは、各確率に平均0の小さなノイズを足し、0未満は0にしてから合計が1になるよう割り直す

段階（「次へ」で進む）
1. 元画像を大きく表示し、右側に10クラスの確率の棒グラフ（6が0.50、0が0.40、9が0.05）を出す。説明文「AIは6と答えたが、0とも迷っている」
2. 画像の上にA・B・Cの3領域を薄い色で重ね、ラベルを付ける。説明文「画像をスーパーピクセルに分ける（実際は数十個）」
3. 領域をランダムに隠した摂動画像を1枚作る。隠した領域は灰色で塗る。棒グラフがその画像に対するAIの確率に変わる。画面下の表に1行追加する（列　A、B、C、6の確率）。説明文「領域をランダムに隠し、AIの確率を記録する」
4. 「次へ」のたびに摂動画像を1枚ずつ追加し、表に行が増えていく。最後に「残りをまとめて作る」で、スライダー「摂動画像の枚数」の枚数まで一気に作る
5. 表を使って、6の確率を A・B・C で線形回帰する。回帰式（例　6の確率 ≈ 0.40 ＋ 0.30A − 0.30B ＋ 0.10C）を表示する。係数は表のデータから実際に最小二乗法で計算する
6. 係数を領域の色にしてヒートマップにする。正の係数は赤、負の係数は青、濃さは係数の大きさ。説明文「赤い領域があると6の確率が上がる。青い領域は下げる」
7. クラス切り替えボタン（0・6・9）を表示し、押したクラスで回帰し直してヒートマップを切り替える。説明文「多クラスでは、同じ表を使ってクラスごとに回帰する」
8. 0・6・9のヒートマップを横に並べ、その後ろに残り7クラス分の小さなヒートマップを重ねて「10枚」と表示する。説明文「クラスごとに説明が10枚できる。6と0の関係は、2枚を見比べないと分からない」
9. 「6 − 0」のボタンで、6の確率から0の確率を引いた値（6寄りか0寄りか）を回帰したヒートマップを1枚出す。説明文「6と0の差を目的変数にすれば、0から6へ確率が移る理由が1枚で読める」

スライダー
- 摂動画像の枚数（5〜50、初期値20）
- 1つの領域を隠す確率（0.2〜0.8、初期値0.5）
- AIの出力のゆらぎ（0〜0.10、初期値0）
```

## プロンプトB　仮定1の確かめ方（動くクラスの数と必要な軸の数）

```
[共通の指定]

テーマ　説明したい点のまわりで、AIの確率がどのクラスでどれだけ動くかを測り、「動くクラスの数」と「必要な軸の数」を数える手順を見せる

登場するもの
- 2次元平面（座標 −1〜1）。AIは10クラスの確率を返す。クラス2・3・9の3つの領域が原点付近で接している
  - 各クラスのスコア　s2 = k×(−0.8x + 0.6y)、s3 = k×(0.8x + 0.6y)、s9 = k×(−1.0y)、残りの7クラス（0,1,4,5,6,7,8）は s = −3（定数）
  - 確率はソフトマックス p = exp(s) / Σexp(s)。k はスライダー「境界のくっきりさ」
  - 平面の各点を、確率が最大のクラスの色で薄く塗る（2は赤、3は青、9は緑）。領域の境界は白い線
  - 各領域に、そのクラスの色の丸いデータ点を20個ずつランダムに置く
- 説明したい点は黄色い星。初期位置は (−0.05, 0.08)。ドラッグで動かせる
- 摂動データは白い点（細い濃紺のふち）。星を中心とした正規分布（標準偏差はスライダー「摂動の広さ」）

段階（「次へ」で進む）
1. 平面、データ点、星を表示する。右に星でのAIの確率（10クラスの棒グラフと数値）を出す
2. 星のまわりに破線の円を描き、摂動データ（スライダー「摂動データの数」の数）を星からはじけるように撒く
3. 1点ずつ光らせ、その点のAIの確率（10個の数の列）を右に表示する。次の点に移るときに前の列は消す。最初の3点はゆっくり、そのあと「残りを一括」で全点を計算する
4. 光らせた点の確率から星の確率を引いた「ずれ」（10個の数、和は0）を、クラスごとの上下の棒（中央線から上がプラス、下がマイナス）で表示する。説明文「確率が高くても動かないクラスはずれが0になる」
5. 全点のずれについて、クラスごとにずれの2乗を足していく様子を、10本の棒グラフが伸びるアニメーションで見せる。最後に割合（%）にして大きい順に並べ、累積が95%に届くところに線を引き、それまでのクラスを強調する。「動くクラス ○個」を大きく表示する
6. ずれ（10次元の点）の集まりにPCA（中心化しない。ずれの行列の2乗和を最もよく表す向きを順に求める）をかける。10×10の行列 ΣdᵀD の固有値分解はヤコビ法などで実装する。各軸がずれ全体の何%を表すかを棒グラフで示し、累積が95%に届く本数を「必要な軸 ○本」と大きく表示する
7. ずれを1本目と2本目の軸の上に散布図で並べ、1本目・2本目の軸を矢印で描く。各軸の向きを「2が下がり、3と9が上がる」のように、重みの大きい上位3クラスの符号から日本語で表示する

スライダーと操作
- 摂動の広さ（0.02〜0.5、初期値0.15）
- 摂動データの数（50〜600、初期値300）
- 境界のくっきりさ k（1〜15、初期値5）
- 星をドラッグして位置を変えられる。境界から離すと動くクラスが1個（ずれがほぼ0）、3つの境界が接する点に近づけると3個になることを確かめられるようにする
- 「元の点からのずれ」のほかに、表示の切り替えで「確率そのもの」の棒グラフも見られるようにする（引き算をする理由を比べて見せるため）
```

## プロンプトC　決定係数 R² による評価

```
[共通の指定]

テーマ　説明（局所的な線形モデル）がAIの確率をどれだけ再現できているかを、決定係数 R² で測る手順を見せる。ずれを平面上の棒で表し、集計する

登場するもの
- プロンプトBと同じ2次元平面とAI（クラス2・3・9の領域が原点付近で接する。境界のくっきりさ k）
- 説明したい点（黄色い星、ドラッグ可）
- 学習用の摂動データ（白い点）と、評価用の摂動データ（白い四角）。どちらも星を中心とした正規分布で、評価用は学習用と別に作る
- 説明　学習用の点で、10クラスの確率を座標 (x, y) から線形回帰したもの（クラスごとに 確率 ≈ a + b·x + c·y）。星に近い点ほど重みを大きくする重み付き最小二乗法（重み = exp(−距離² / (2×0.75²))）
- 圧縮した説明　学習用の点の確率にPCAをかけて上位 q 本の軸に射影し、その軸のスコアを線形回帰してから10クラスの確率に戻したもの。q はスライダー（1, 2, 3）

段階（「次へ」で進む）
1. 平面、星、学習用の摂動データを表示する
2. 説明を作る。平面全体に、説明が予測する「最大の確率のクラス」の境界を点線で重ね、AIの本当の境界（実線）と比べられるようにする。説明文「説明は、星の近くでAIを平面（線形）で近似したもの」
3. 評価用の摂動データ（四角）を撒く。説明文「評価には、説明を作るのに使っていない点を使う」
4. 評価用の点を1つずつ光らせ、その点の上に2本の縦棒を立てる。朱色の棒＝説明のずれ（AIの確率と説明の予測の差を10クラス分2乗して足したもの）、灰色の棒＝平均で答えたときのずれ（AIの確率と、評価用の点全体の平均の確率の差を2乗して足したもの）。右に、その点のAIの確率と説明の予測を並べた棒グラフ（クラス2・3・9とその他）を出す
5. 全点の棒を立てたあと、棒が右側の2つの集計エリアに飛んでいき、積み上がる。「説明のずれの合計」と「平均で答えたときのずれの合計」
6. R² = 1 − 説明のずれの合計 ÷ 平均で答えたときのずれの合計 を計算し、0〜1のメーターと数値で表示する。説明文「1に近いほど、説明がAIの振る舞いを再現できている。0なら平均を答えるのと同じ」
7. 比較表示　通常の説明（圧縮なし）と、圧縮した説明（q本）の R² を並べ、その差を「圧縮で失う R²」として表示する

スライダーと操作
- 摂動の広さ（0.02〜0.6、初期値0.15）。広げると線形で近似しにくくなり、R² が下がることを見せる
- 境界のくっきりさ k（1〜15、初期値5）
- 摂動データの数（学習用・評価用それぞれ、50〜600、初期値300）
- 圧縮の軸の数 q（1、2、3）。星を3つの境界が接する点に置いて q=1 にすると R² が下がり、q=2 でほぼ通常の説明と同じになることを確かめられるようにする
- 星をドラッグして位置を変えられる
```
